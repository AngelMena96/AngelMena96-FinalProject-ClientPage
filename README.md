# AngelMena96-FinalProject-ClientPage
Description

This is a sample page for a green energy company. It includes a home page giving a mission statement and an overview of the services offered.
The About Us page has more detailed information on the company background and a timeline of milestones achieved by the company. THe rest of the 
pages include articles about green energy and a detailed description of the services offered. The contact us page has fields for the user to 
input their contact information to reach out to the company.

Features
HTML - The page includes various HTML elements such as header, paragraphs, form, images, and links. 
CSS - the css file edits the background, fonts, and images of the web page
Responsiveness - The web page adapts mobile devices as well. it resizes the fonts, image sizes, and margins making it more easily readable in smaller screens.

How to Run
TO run the page, start the Home.html file or copy the link provided in the Live Site Link above into your browser.

Technologies Used
Unsplash and Pexels were used to aquire all images in this project.
Coolors.com was used to generate a color scheme for the website.
